# Ghosts'n Goblins Music Box

**Version:** 1.0  
**Development:** 2015  
**Platform:** Commodore Plus/4  
**Language:** 6502 assembly  
**Assembler:** KickAssembler  
**Status:** Completed and tested; archived for preservation

## About

A Commodore Plus/4 music box featuring music from different versions and arrangements of Ghosts'n Goblins and Ghouls'n Ghosts, together with a title picture. The project began while Chronos was moving from DASM to as65 and Csabo's Plus4IDE environment. The source has since been converted to KickAssembler.

## Music credits

- Ghosts'n Goblins (two tunes): **Mark Cooksey**
- Ghouls 'n Ghosts (alternate): **Tim Follin**
- Ghost'n'Goblins Remix: **Thomas Mogensen (DRAX)**, Vibrants (1990)
- 6R6 music: **Glenn Rune Gallefoss (6R6)**

The C64 SID music can be played using a SID card or through the Plus/4 TED sound hardware.

## Graphics credits

The multicolor title picture is credited in the source to **STE'86**. The character set was adapted from a Nostalgia release.

## Building

The sources have been converted to **KickAssembler**. Earlier references to DASM, as65 or Plus4IDE describe historical development tools, not current build requirements. The original source files are preserved without modification.
